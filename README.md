# d3dcrypted

Infrastructure, security, and the AI systems that run on top of them.

I have spent years building and running infrastructure, and it is still how I read everything else: virtualization, networking, identity, backup, hardening. Cybersecurity and AI came later, mostly because both keep running into the same problems I already knew from the other side. A fair amount of it runs on hardware in my house.

Most of what is in these repositories was drafted with an AI assistant. I set the direction, decide what is worth keeping and review the result. That is the method I am testing in public.

## What I am working on

- [LLMOps building blocks](https://github.com/d3dcrypted/llmops): five small demos in one repository. Retrieval with citations, token-overlap evaluation gates, a llama.cpp serving stack with metrics, fine-tuning data contracts, input-filter heuristics. No model is trained or evaluated there; each README lists its limits. The tests need no GPU, no API key and no network.
- [IT team framework](https://github.com/d3dcrypted/it-team-framework): how I run an IT assessment with agents, one per domain, plus a gatekeeper and a validator.
- [Second brain patterns](https://github.com/d3dcrypted/hermes-honcho-second-brain-pattern): durable context for CLI agents, kept as plain markdown in a vault I can read and edit.
- [LinkedIn agent](https://github.com/d3dcrypted/linkedin-agent): a raw thought in, a sourced and humanized draft out.

## How I work

Simple over clever, evidence over assumption. If a design needs me in the room to explain it, it is not finished.

Everything here is public and readable. If something in it is wrong, I would like to know.
